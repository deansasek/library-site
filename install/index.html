Install Library on macOS with one command

Install Library with one command in Terminal. Requires macOS 26 or later.

Applies to the current release of Library. Last reviewed October 15, 2026.

On this page

  1. Requirements
  2. Install
  3. First steps

Requirements

Operating system
macOS 26 or later
Developer tools
Command Line Tools for Xcode, installed for you if missing

Install

Paste this into Terminal. It downloads the latest release, checks its SHA-256 checksum, and builds and installs Library.app in your Applications folder. It installs the Command Line Tools for Xcode first if they are missing, and it needs nothing else installed beforehand.

Terminal
cd "$(mktemp -d)" && tag="$(curl -fsSIL -o /dev/null -w '%{url_effective}' https://github.com/deansasek/library/releases/latest | sed 's#.*/tag/##')" && ver="${tag#v}" && curl -fsSL -O "https://github.com/deansasek/library/releases/download/$tag/Library-$ver.zip" -O "https://github.com/deansasek/library/releases/download/$tag/Library-$ver.zip.sha256" && shasum -a 256 -c "Library-$ver.zip.sha256" && unzip -q "Library-$ver.zip" && "./Library-$ver/install.sh"

Installing the Command Line Tools may open a window, and it can ask for your Mac password. Finish the window, and the install continues on its own.

First steps

  1. Press ControlSpace to open Quick Open. Type a name and press Return.
  2. Choose Edit Library… from the menu bar icon to add bookmarks and apps.
  3. Turn on Open at Login in Settings > General to start Library when your Mac starts.

Updates

Library checks for updates itself. Check for Updates… offers a newer version. If you choose to install it, Library opens Terminal, downloads the release from GitHub, checks its SHA-256 checksum, builds and installs it, and deletes the download. It does not install silently. Your library and pinned clipboard items are kept.

The command above keeps no copy of the source, so there is nothing to update from. To update, run the command again.

To learn how often Library checks, read Stay up to date.

Uninstall

  1. Quit Library.
  2. Move Library.app from your Applications folder to the Trash.

Older versions kept a copy of the source in ~/Library/Application Support/Library. If that folder exists, move it to the Trash too.

Your library and clipboard history stay in ~/.library. Removing the app doesn't remove that folder. Move it to the Trash too if you want to delete your data.
