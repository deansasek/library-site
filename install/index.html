Install

Install Library with one command in Terminal. Requires macOS 26 or later.

Requirements

Operating system
macOS 26 or later
Developer tools
Xcode Command Line Tools

Install

Paste this into Terminal. It builds Library and installs Library.app in your Applications folder. The source is kept out of the way, in Application Support:

git clone https://github.com/deansasek/library.git "$HOME/Library/Application Support/Library/Source" && "$HOME/Library/Application Support/Library/Source/install.sh"

First steps

  1. Press Control-Space to open Quick Open. Type a name and press Return.
  2. Choose Edit Library… from the menu bar icon to add bookmarks and apps.
  3. Turn on Open at Login in Settings > General to have Library start with your Mac.

Updates

Library checks for updates itself, and Check for Updates… installs them. Your library and clipboard history are kept.

If you installed with the command above, Library remembers the cloned source, so Check for Updates… updates from it. The release zip has no update script, so Library sends you to the release page instead.

See Stay up to date in the guide for how often Library checks.

Uninstall

  1. Quit Library.
  2. Move Library.app from your Applications folder to the Trash.
  3. Move the Library folder in ~/Library/Application Support to the Trash. It holds the source you cloned.

Your library and clipboard history are kept in ~/.library, and removing the app doesn't remove that folder. Move it to the Trash too if you want to delete your data.
