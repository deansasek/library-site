Install

Install Library with one command in Terminal. Requires macOS 26 or later.

Applies to the current release of Library. Last reviewed October 14, 2026.

    Requirements

    Operating system
    macOS 26 or later
    Developer tools
    Xcode Command Line Tools

    Install

    Paste this into Terminal. It builds Library, puts Library.app in your Applications folder, and keeps the source code out of the way in Application Support.

    Terminal
    git clone https://github.com/deansasek/library.git "$HOME/Library/Application Support/Library/Source" && "$HOME/Library/Application Support/Library/Source/install.sh"

    First steps

    1. Press Control-Space to open Quick Open. Type a name and press Return.
    2. Choose Edit Library… from the menu bar icon to add bookmarks and apps.
    3. Turn on Open at Login in Settings > General to start Library when your Mac starts.

    Updates

    Library checks for updates itself. Choose Check for Updates… to install one. Your library and clipboard history are kept.

    If you installed with the command above, Check for Updates… updates from the source you cloned. A release zip has no update script, so Library sends you to the release page instead.

    To learn how often Library checks, read Stay up to date.

    Uninstall

    1. Quit Library.
    2. Move Library.app from your Applications folder to the Trash.
    3. Move the Library folder in ~/Library/Application Support to the Trash. It holds the source you cloned.

    Your library and clipboard history stay in ~/.library. Removing the app doesn't remove that folder. Move it to the Trash too if you want to delete your data.
