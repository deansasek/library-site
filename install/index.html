Install Library on macOS with one command

Install Library with one command in Terminal. Requires macOS 26 or later.

Applies to the current release of Library. Last reviewed October 15, 2026.

On this page

  1. Requirements
  2. Install
  3. First steps

Requirements

Operating system
macOS 26 or later
Developer tools
Command Line Tools for Xcode, installed for you if missing

Install

Paste this into Terminal. It installs the Command Line Tools for Xcode if they are missing, builds Library, and puts Library.app in your Applications folder. It downloads the source to a temporary folder, so it needs nothing installed beforehand.

Terminal
cd "$(mktemp -d)" && curl -fsSL https://github.com/deansasek/library/archive/refs/heads/main.zip -o library.zip && unzip -q library.zip && ./library-main/install.sh

Installing the Command Line Tools may open a window, and it can ask for your Mac password. Finish the window, and the install continues on its own.

First steps

  1. Press Control-Space to open Quick Open. Type a name and press Return.
  2. Choose Edit Library… from the menu bar icon to add bookmarks and apps.
  3. Turn on Open at Login in Settings > General to start Library when your Mac starts.

Updates

Library checks for updates itself. Check for Updates… offers a newer version. If you choose to install it, Library opens Terminal, clones the release, and runs its installer. It does not install silently. Your library and pinned clipboard items are kept.

To update a clone made with the command above, run update.sh in the Source folder.

To learn how often Library checks, read Stay up to date.

Uninstall

  1. Quit Library.
  2. Move Library.app from your Applications folder to the Trash.
  3. Move the Library folder in ~/Library/Application Support to the Trash. It holds the source you cloned.

Your library and clipboard history stay in ~/.library. Removing the app doesn't remove that folder. Move it to the Trash too if you want to delete your data.
