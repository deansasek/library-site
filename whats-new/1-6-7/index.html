What's new in Library 1.6.7

Version 1.6.7 · Released October 16, 2026

Library 1.6.7 fixes the selected row in Quick Open, which showed black text in light mode. It now uses the same white text as other selected rows on the Mac.

Released October 16, 2026. Last reviewed October 15, 2026.

Fixed

  • In light mode, the selected result in Quick Open shows white text, as other selected rows on the Mac do.
  • The selected action in Quick Open's actions menu uses the same selected-text color.

Download

Download Library 1.6.7 from the GitHub release page, or install it with the command on the install page.
