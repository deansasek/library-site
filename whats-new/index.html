What's new in Library: release notes

Every release of Library, newest first, with what changed in each. Major and minor releases also have their own page.

Library 1.6.8

Released October 16, 2026. What's new.

  • Installing from the source download no longer stops with a missing script, and it builds the version it was released as.

Library 1.6.7

Released October 16, 2026. What's new.

  • In light mode, the selected result in Quick Open shows white text, as other selected rows on the Mac do.
  • The selected action in Quick Open's actions menu uses the same selected-text color.

Library 1.6.6

Released October 16, 2026. What's new.

  • Hold Option and click a bookmark, command, or app in the Library menu to see Edit…, which opens its Get Info.
  • Find is in the Edit menu, with ⌘F, and moves to the search field.
  • Quick Open shows its actions in an ellipsis menu, and its results are a standard list.

See all 11 changes in What's new

Library 1.6.5

Released October 16, 2026. What's new.

  • Choose a custom color for an item in Get Info, with the system color picker.
  • Preview files in Quick Open. Documents and images appear in Quick Look, and CSV and TSV files appear as a table.
  • Search scopes and suggestions in Edit Library: All, Bookmarks, Apps, Commands, and Folders.

See all 27 changes in What's new

Library 1.6.4

Released October 15, 2026. What's new.

  • Help is in the Library menu, under Help. It has Library Help, Keyboard Shortcuts, Welcome Tour, Report an Issue, and Support Library.
  • The welcome tour has pages for finding things, copying and pasting, organizing, and working with other apps.

Library 1.6.3

Released October 15, 2026. What's new.

  • Screenshots and recordings are added to clipboard history as you take them. Turn this off in Settings > Clipboard.
  • Confirm Terminal Commands asks before a terminal command runs. It is off by default.
  • Support Library in the Help menu opens the support page.

See all 5 changes in What's new

Library 1.6.2

Released October 15, 2026. What's new.

  • Each folder can show or hide Open All.
  • Link check results are described in plain language.
  • Library is licensed under the MIT License.

See all 4 changes in What's new

Library 1.6.1

Released October 15, 2026. What's new.

  • Update in Terminal downloads, builds, and installs the new version, then removes the download. Your library is kept.
  • New labels use Apple capitalization.

Library 1.6.0

Released October 15, 2026. What's new.

  • Keep clipboard history across restarts. Turn it on in Settings > Clipboard. It is off by default, and turning it off deletes the saved history.
  • Smart actions for detected text. Text with an address, a phone number, or a date gets Open in Maps, Copy Phone Number, or Add to Calendar in Quick Open, under Tab.
  • Smart Punctuation in Copy as. It turns straight quotes and dashes into curly quotes, em dashes, and ellipses.

See all 13 changes in What's new

Library 1.5.0

Released October 14, 2026. What's new.

  • Keep the library in iCloud Drive, off by default. Turn it on in Settings > General.
  • Paste a queue of items, one at a time, in order.
  • Filter clipboard history by app. Type from Safari in Quick Open.

See all 20 changes in What's new

Library 1.4.0

Released October 14, 2026. What's new.

  • Pinned clipboard items are encrypted with a key kept in your Keychain.
  • Quick Open narrows its results as you type, more quickly.
  • Quick Open stays open while you use a Quick Look preview.

See all 6 changes in What's new

Library 1.3.0

Released October 14, 2026. What's new.

  • A Help menu with the guide, the keyboard shortcuts, a tour, and a way to report an issue.
  • Search fields, Quick Open actions, and buttons have labels for VoiceOver. Decorative icons are hidden from it.
  • Services link Finder folders, and no longer create empty groups.

Library 1.2.0

Released October 14, 2026. What's new.

  • Import bookmarks from Safari and Chrome with File > Import Bookmarks…. They go into one folder.
  • Preview a clipboard item in Quick Look with Space.
  • Add apps and folders from Finder with Services.

See all 7 changes in What's new

Library 1.1.0

Released October 14, 2026. What's new.

  • Quick Open respects Reduce Motion.
  • App icons refresh when Library is updated.
  • Library never runs commands from links.

See all 4 changes in What's new

Library 1.0.0

Released October 14, 2026. What's new.

  • Bookmarks, apps, folders, and terminal commands in the menu bar, opened with a click or a shortcut.
  • Quick Open, which searches your library from anywhere.
  • Services, so you can add a selected link from other apps.
