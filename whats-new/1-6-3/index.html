What's new in Library 1.6.3

Version 1.6.3 · Released October 15, 2026

Library 1.6.3 adds screenshots and recordings to clipboard history, a setting to confirm terminal commands, and a way to install the Command Line Tools.

Released October 15, 2026. Last reviewed October 15, 2026.

New

  • Screenshots and recordings are added to clipboard history as you take them. Turn this off in Settings > Clipboard.
  • Confirm Terminal Commands asks before a terminal command runs. It is off by default.
  • Support Library in the Help menu opens the support page.
  • The install command installs the Command Line Tools if they are missing.

Fixed

  • Copying an item back from the clipboard menu keeps its source app.

Download

Download Library 1.6.3 from the GitHub release page, or install it with the command on the install page.
