Library

Everything you open and copy, one shortcut away.

View on GitHub Install

Features

Quick Open

Press Control-Space from anywhere to open your library, clipboard, and snippets.

Clipboard history

Bring back anything you copied a moment ago and copy it again with one choice.

Snippets

Keep the text you type often, such as an address or a standard reply, and paste it in a moment.

Smart actions

Addresses, phone numbers, and dates are detected as you work, and Smart Punctuation tidies your text.

Install

Paste this into Terminal. It builds Library and installs Library.app in your Applications folder.

git clone https://github.com/deansasek/library.git "$HOME/Library/Application Support/Library/Source" && "$HOME/Library/Application Support/Library/Source/install.sh"

Requires macOS 26 or later.
