Get started

Install Library first, then follow the first steps in Install.

Open anything

Bookmarks, apps, folders, and terminal commands open from the menu bar, a keyboard shortcut, or Spotlight. To open an item the other way, hold Option while you click it.

  • Bookmarks open in a new tab or a new window.
  • Apps come to the front. To start a new copy, add a launch argument, such as --profile work.
  • Terminal commands run in a login shell in a new Terminal window. Add only commands you trust.
  • Folders open as submenus. Choose Open All in a folder to open its bookmarks and apps, one after another. Library skips dividers, terminal commands, templates, and apps that are no longer installed. It asks first when more than five items would open.

Quick Open

Quick Open is a search box that floats over your screen. It searches your library, your clipboard history, and your snippets, and it runs the result you choose.

Open Quick Open

  1. Press Control-Space. This is the default shortcut.
  2. Type to search. The search field has the keyboard as soon as Quick Open opens.
  3. Press Return, or click a row, to run it. Quick Open closes.

Press the same shortcut again to close Quick Open without choosing anything. Quick Open also opens with the library://search address.

Quick Open appears centered on the screen under the pointer. It stays in place while you type. It appears over full-screen apps and on every Space.

To change the shortcut, go to Settings > Shortcuts and change Show Quick Open. Control-Space can conflict with the macOS input source shortcut. If it does, pick another key combination.

Search

Quick Open splits your text into words. Each word must match something about the item, and every word must match for the item to appear.

Library items and snippets are scored for each word:

MatchScore
The start of the name, or the start of a keyword4
Anywhere inside the name3
Target, folder, or keywords (including the color)2
The letters in order inside the name, with others between them1

An item's score is the sum of its word scores. Higher scores come first. Items with the same score are ordered by how often you have opened them, most first. Items you have not opened keep their order in the library.

Keywords, the item's color, and the folder name are all searched. Typing red finds items you gave the red color.

What appears with an empty search

With the search field empty, Quick Open shows, in order:

  1. Suggested: the link or app on the clipboard, or a link selected in the app in front, when it is not in your library yet. See Add a suggested link or app.
  2. Frequently Used: up to five items you have opened at least twice.
  3. The whole library, in the same order as the Library menu.
  4. Clipboard: the five first clipboard items. Pinned items come first.

What appears with a search

With text in the search field, results appear in these groups, each with its own heading:

  • Top Hit: the first result. Return runs it.
  • Library: matching items.
  • Clipboard: up to eight matching clipboard items, pinned items first, then newest first.
  • Snippets: matching snippets.
  • Suggestions: a web address you typed, or a suggested link or app.

Clipboard matches must contain every word, ignoring case. They are not ranked by score.

Web addresses

If the search text is a web address, Quick Open adds two rows:

  • Open followed by the host, for example Open example.com.
  • Add "example.com" to Library.

A web address has no spaces. It is either a full address with ://, or a host name with a dot and a top-level domain of at least two letters, such as example.com/path. localhost is not treated as a web address.

Add a suggested link or app

When the clipboard holds a web link or an application that is not in your library, Quick Open offers to add it. It is listed under Suggested with an empty search. It is also listed when the search is at least two characters long and is part of the words "add to library", such as ad or to li.

A link selected in the app in front is used first, if Quick Open can read it. Choosing the suggestion adds it to the library. If the page can be read, Library names the new bookmark from its title when Name new bookmarks from their pages is on.

Search only one app's copies

Type from and the name of an app to see only the clipboard items you copied while that app was in front. For example, from Safari shows Safari copies. Add words after the app name to search those copies, such as from Safari invoice.

The name must match an app that appears in your clipboard history, ignoring case. When two apps match, the longer name wins. When the search starts with from <app>, the library is not searched.

Option-Return

For a library item that can open two ways, Option-Return does the opposite of the item's usual setting:

  • A web bookmark opens in a new tab, or in a new window.
  • An app is brought forward, or a new instance is started.

The labels in the actions list name the two ways. For clipboard items and snippets, Option-Return does the same as Return.

Option-click does not change how a row opens in Quick Open. Use Option-Return.

Space

Space previews the selected clipboard item in Quick Look. Press Space again, or Escape, to close the preview.

Space types a space when the selected row is not a clipboard item, or when the clipboard item has nothing to preview. This is true even with an empty search.

Actions

Press Tab, or right-click a row, to see its actions. The actions depend on the row.

Library item (a bookmark, app, command, or folder item):

  • Open, and the other way to open the item, where it applies.
  • Copy Link, for a bookmark.
  • Copy Clean Link, for a bookmark. It removes tracking parameters such as utm_source, fbclid, and gclid. The saved link is not changed.
  • Copy as Markdown Link, for a bookmark. Not offered for templates.
  • Copy Command, for a terminal command.
  • Copy Path and Show in Finder, for an app.
  • Add to Reading List, or Mark as Read, Mark as Unread, and Remove from Reading List, for a bookmark in the Reading List.

Clipboard item: see Clipboard. The actions include Copy or Paste, Copy as Plain Text, Copy as, Quick Look, Pin or Unpin, Add to Paste Queue, Add to Library, and Delete.

Typed web address: Copy Clean Link.

Snippet: Copy and Edit.

Choosing an action runs it and closes Quick Open. Choosing Copy as… or another submenu lists its choices in place of the actions.

Preview

The right side of Quick Open shows the selected row in full. It is 280 points wide.

  • Clipboard text: the first 4,000 characters, selectable, with the source app, time, and size.
  • Picture: the picture. A GIF plays.
  • Files: each file's name and icon.
  • Other copies: the number of formats.
  • Library item: its name, icon, and link, command, or path. Its folder appears under it.
  • Snippet: its name and the first 4,000 characters of its text.
  • Locked pinned item: the words Pinned Item, and a Show Pinned Item button. See Clipboard.

Clicking into the preview does not close Quick Open.

Keywords, colors, and notes on an item also affect what Quick Open shows. Notes appear under the item's name in the list.

Limits

  • Clipboard matches in a search: eight.
  • Clipboard items with an empty search: five.
  • Frequently Used: five items, each opened at least twice.
  • Text in a clipboard item is searched up to its first 100,000 characters.
  • The preview shows the first 4,000 characters of text.
  • Each row is 42 points tall. The list shows about seven or eight rows at once and scrolls for the rest.

What it stores and whether it syncs

Quick Open stores nothing of its own. It reads:

  • The library, which is in iCloud Drive when Keep Library in iCloud Drive is on.
  • Clipboard history, which stays on this Mac. See Clipboard.
  • Snippets.
  • Open counts, which set the Frequently Used list, are kept on this Mac.

Notes

  • Quick Open closes when another app comes to the front, when the Spotlight search opens, or when you click elsewhere. It stays open while the Quick Look preview has the keyboard, and while the Touch ID or password prompt is up.
  • A row can be dragged into another app. A clipboard image, file, link, or text is dropped as that type, and Quick Open closes after the drop.

Clipboard

Library keeps a history of what you copy. You can copy an item back, paste it into a text field, pin the items you keep, and queue several items to paste in order. The history is reached from the clipboard menu, from the Clipboard submenu in the Library menu, and from Quick Open.

What it records

Library records each copy with every format it was copied in, so copying an item back loses nothing. It records:

  • Text, and links. A link is text that is a web address.
  • Images. A copied image is kept in one format, PNG when there is one.
  • Files, by name and icon.
  • Any other copy, which shows as Clipboard Item.

Library checks the clipboard about twice a second. A copy appears in the history a moment after it is made.

Copying the same thing again does not add a second entry. The existing entry moves to the top, and keeps its pin.

Library does not record a copy when:

  • The copy is marked as private by a password manager or a system field.
  • The copy is made while a password manager is in front. The apps are 1Password, Bitwarden, KeePassXC, LastPass, Dashlane, Keychain Access, and Passwords.
  • The copy is larger than 25 MB.

Pin an item

Pinned items stay in the history after you quit, and they are never removed by the limits below.

  1. In Quick Open, find the item, and press Tab.
  2. Choose Pin.
  3. To remove the pin, press Tab on the item again and choose Unpin.

Pins are set in Quick Open only. Pinned items show first in the clipboard menu, under Pinned, and first in Quick Open.

Open the clipboard menu

  1. Press Control-Command-V. The menu opens at the pointer.
  2. Choose an item to copy it back, or press a number key from 1 to 9 to choose one of the first nine items.
  3. Hold Option over a rich-text item. Its entry changes to Copy as Plain Text, and choosing it copies the text without formatting.

The menu lists pinned items under Pinned and the 20 most recent other items under Recent. It has Clear History at the bottom. When a text field has the keyboard, the headers say Paste Pinned and Paste Recent, and choosing an item pastes it. See Paste into text fields.

If the clipboard or the selected text in the app in front holds a link or app that is not in your library, the menu starts with a row that adds it.

To change the shortcut, go to Settings > Shortcuts and change Show Clipboard Menu.

The Clipboard submenu in the Library menu

The Clipboard submenu in the Library menu lists the ten first items, pinned items first. Choosing one copies it. It never pastes. It has Clear History, and the paste queue when the queue has items.

Paste into text fields

When Paste into text fields is on, choosing an item from Quick Open or the clipboard menu pastes it, if a text field had the keyboard when the menu or Quick Open opened. Otherwise it copies the item.

Library checks for a text field as the menu or Quick Open opens. When you then choose an item, Library presses Command-V in the app in front, a moment later.

This needs Accessibility access. Without it, choosing an item copies it.

Paste queue

Use the paste queue to paste several items in order.

  1. In Quick Open, find an item, press Tab, and choose Add to Paste Queue.
  2. Repeat for each item. The queue lists them in order in the clipboard menu.
  3. Choose Paste Next in the clipboard menu. Library copies the first item and removes it from the queue.
  4. Press Command-V in the app you are working in. Repeat from step 3 for the next item.

Clear Queue removes every item from the queue. The queue is kept in memory only, so it is empty when Library starts.

Choosing Paste Next copies the item. It does not paste it into the app for you.

Copy as

Copy as turns a text item into a new clipboard entry. The original stays in the history as it was.

  1. In Quick Open, find a text item, press Tab, and choose Copy as….
  2. Choose one of the options:
    • Plain Text copies the text without formatting.
    • Trimmed Whitespace removes spaces and line breaks at both ends.
    • Lowercase and Uppercase change the case.
    • Joined Lines turns each line break into a space.
    • Smart Punctuation turns straight quotes into curly quotes, ' into ’, -- into an em dash, and ... into an ellipsis. A quote opens when it comes first or follows a space, a bracket, or a dash. An apostrophe before a year, such as '90s, becomes ’90s.

Copy as is offered for text items only. Links and pictures do not have it.

Markdown links

Use Markdown links to paste a title and its address in a document.

  1. In Quick Open, find a bookmark, or a copied link, press Tab, and choose Copy as Markdown Link.
  2. Paste into a Markdown document. The result is [Title](address).

The title is the bookmark's name, or the copied link's host. Characters that have a meaning in Markdown are escaped. Spaces and parentheses in the address are percent-encoded. In a rich-text field, the title pastes as a link.

Templates do not offer this action.

Filter by the app you copied from

Each copy records the app that was in front when you copied it. You can list only the copies made in one app.

  1. Open Quick Open.
  2. Type from and the app's name, such as from Safari.
  3. Add words after the name to search those copies, such as from Safari invoice.

The name matches an app in your history, ignoring case. Copies made while Library itself was in front have no app name, so they do not appear in any app filter.

Quick Look and the Space key

Quick Look shows a clipboard item in the system preview panel.

  • In Quick Open, select a clipboard item and press Space. Press Space again, or Escape, to close the preview.
  • In Quick Open, press Tab, and choose Quick Look.

Text and pictures are shown from a temporary copy. Files are shown where they are. Items with nothing to show, such as a format Library does not display, cannot be previewed.

The temporary copies are in a private folder in the system temporary folder. They are deleted when the preview closes. Any left by a quit or a crash are deleted the next time Library starts.

Clicking into the preview does not close Quick Open.

Actions for text

For a text item, Quick Open's Tab actions also include three actions that work on the text. Each appears only when the text has the matching thing in it:

  • Open in Maps opens an address in Apple Maps.
  • Copy Phone Number copies the number with its digits and plus sign only.
  • Add to Calendar opens Calendar's add-event sheet for a date or time. The event's title is the first line of the text. An event with no length lasts one hour.

Library finds these on this Mac. It looks at the first 10,000 characters of the text.

Play copied GIFs

Browsers copy a still picture when you copy an animated GIF. With Play copied GIFs on, Library downloads the original GIF from the page, so it plays in the list and the preview.

  • The setting is off by default.
  • It applies to copies made while it is on. It does not download GIFs for copies you made earlier.
  • Library asks the page's server for the GIF file only. It sends no cookies, and it stops after 10 seconds or 25 MB.
  • Animated GIFs show a small animated icon in the list.

Turn it on in Settings > Clipboard.

Lock pinned items

The lock asks for Touch ID or your Mac password before pinned items are shown or copied.

  1. Open Settings > Clipboard.
  2. Turn on Require Touch ID or password to show pinned items.

Library will not turn the lock on when your Mac has neither Touch ID nor a password. Add a password in System Settings, then turn it on again.

With the lock on:

  • A locked pinned item shows a lock icon and the words Pinned Item, in the list, the menu, and the queue.
  • Search does not find a locked pinned item.
  • Copying, Quick Look, Show Pinned Item, Add to Library, and Paste Next ask you to authenticate first. If you cancel, nothing changes, and the item stays locked.
  • Pin, Unpin, Delete, and Add to Paste Queue do not ask, and they do not show the item's text.

After you authenticate, the items stay unlocked until one of these happens:

  • You choose Lock Pinned Items in the Library menu. The item appears only when the lock is on, and it is dimmed while the items are already locked.
  • Your Mac goes to sleep.
  • You turn the setting on. Turning it on always locks the items.
  • Library quits. The next launch starts locked.

Keep clipboard history across restarts

By default, unpinned history is kept in memory and is gone when Library quits. Pinned items are always kept.

To keep unpinned history:

  1. Open Settings > Clipboard.
  2. Turn on Keep clipboard history across restarts.

With this on:

  • The unpinned history is saved to a file when a copy is made, about a second after it.
  • Copies from password managers and copies marked private are never saved.
  • Images over 5 MB are not saved. Other items are.
  • Turning the setting off deletes the saved history file.

To copy the newest saved item to the clipboard when Library opens, turn on Put the Latest Item on the Clipboard When Library Opens. It needs the setting above. It does nothing when you have copied something since Library opened. A password copied before a restart could be pasted by someone else at this Mac.

Limits

  • Unpinned items: the 50 most recent. Pinned items are not counted.
  • Memory: the history holds up to 200 MB in total, including pinned items. When the total is over, the oldest unpinned items are removed first.
  • Each copy: up to 25 MB. A larger copy is not recorded.
  • Search: the first 100,000 characters of each text item are searched.
  • Saved images: 5 MB each, when history is kept across restarts.
  • Clipboard menu: the first nine items have number keys. The menu lists pinned items, then up to 20 recent items.

What it stores and whether it syncs

  • Pinned items are saved in ~/.library/clipboard.json.
  • Unpinned history is saved in ~/.library/clipboard-history.json, only when Keep clipboard history across restarts is on.
  • Both files are encrypted with a key kept in your login Keychain, on this Mac only.
  • The folder is readable only by you. Each file is readable only by you.
  • If a file cannot be read, it is moved aside, to clipboard-damaged.bin or clipboard-history-damaged.bin, and is not deleted.

Clipboard history does not sync. It stays on this Mac, even with Keep Library in iCloud Drive on. Export does not include clipboard items.

Caveats

  • Turning off Keep clipboard history stops recording. It does not clear what is already in the history.
  • A copy is recorded about half a second after you make it.
  • Hold Option for Copy as Plain Text only works on rich-text items in the clipboard menu. Other items do not offer that choice.
  • The paste queue is cleared when Library quits.
  • Quick Look temporary copies are removed when Library starts, so a preview left open by a crash does not leave its copy behind.

Save snippets

Save text you type often, such as an address or a standard reply, as a snippet. To add one, choose File > New Snippet…, or click Snippets in the Library window.

To copy a snippet, type its name or a keyword in Quick Open, then press Return.

Edit Library

Edit Library is the window where you manage everything in your library: add, move, sort, search, edit, delete, merge, import, and back up. Open it from the Library menu with Edit Library…. The window itself is titled "Library."

Open the window

  1. Click the Library icon in the menu bar.
  2. Choose Edit Library….

The window opens at the size and position you last left it. It cannot be smaller than 680 by 320 points.

The window

  • Toolbar: Edit… (⌘I), Add (the + menu), Snippets, Get Info, Share, and Delete. Edit, Get Info, and Delete need a selection. Share works for one selected item that has a link or an application. It is off for templates and terminal commands.
  • Columns: Name, Shortcut, and Path. Path shows the address, the command, or the application path, with its arguments.
  • Sort menu (the arrows at the right of the header). See Sort.
  • Reading List section at the top, when it has items. See Reading List.
  • Recently Deleted section at the bottom, when it has items. See Recently Deleted.
  • Footer: shows the iCloud Drive state when the library is kept in iCloud Drive.
  • Subtitle: the number of bookmarks and applications in view.

An empty library shows "Your Library Is Empty" with an Add Bookmark button.

Add items

Choose + in the toolbar, or use File > New:

Every sheet has a Folder menu. Choose Top level or an existing folder.

You can also drag items into the window:

  • Drag an application from the Finder to add it.
  • Drag a web link from a browser to add it as a bookmark, named after its host. If the link is already in your library, the existing item moves to the top level instead of being added twice.
  • Other files and folders dropped on the window are ignored. To add a folder, use the Services item described in Services.

If Name new bookmarks from their pages is on in Settings, a bookmark you add by drag or by Services takes its page's title. See Settings.

Select items

  • Click a row to select it. Shift-click and Command-click select several rows, as in other Mac lists.
  • Double-click a single row to open it.
  • Press Return to rename the selected row. Press Escape or Return to finish.
  • Press ⌘I, or choose Edit… from the toolbar or the right-click menu, to open Get Info. With several rows selected, Get Info opens the bulk edit sheet.

Sort

  • Click a column heading to sort by it. The first click sorts ascending, the second descending, and the third returns to Your Order. An arrow shows the column in use.
  • Choose the sort menu, then Your Order, Name, Path, Most Used, or Recently Opened. Name and Path start ascending.
  • Shortcut sorts by the first shortcut of each item. Items with no shortcut sort last.
  • Path sorts by the address, or the command, or the application path.
  • Most Used and Recently Opened order items by how often and how recently you opened them. Folders keep their places at the top.
  • Folders are listed before items in every sorted order.

Sorting changes only what this window shows. Your own order, which the Library menu uses, does not change. The sort is not saved when you quit.

Search

Type in the search field at the top right of the window. The prompt reads "Name, URL, command, or keyword."

  • Each word you type must match. For example, jira ops finds an item only if both words appear in its name, URL, command, or keywords.
  • A folder whose name matches shows all of its contents.
  • Any other folder shows only the items inside it that match.
  • Dividers never match.
  • Recently Deleted is filtered by the same search.

Reorder and move

  • Drag onto a folder to move the selected rows into it.
  • Drag onto a row that is not a folder to place the dragged rows directly before it. This works only in Your Order. While a column or the sort menu sorts the list, a drop before a row does nothing.
  • Drag onto empty space to move the rows to the top level.
  • Move to in the right-click menu lists Top level and every folder. Items that would end up inside themselves are not moved.
  • Dragging a selected row moves the whole selection.

A bookmark, an application, or a folder link can be dragged into another app. It drops the link or the application file. Folders, dividers, templates, and terminal commands stay inside the window.

Right-click menu

The menu groups its commands as follows:

  1. Open, Open All (folders only), Show in Finder (applications only).
  2. Edit…, Rename.
  3. Add to Reading List, Mark as Read, Mark as Unread, Remove from Reading List, as they apply.
  4. Move to, Share….
  5. Delete, alone at the bottom.

In Recently Deleted, the menu offers only Restore and Delete Immediately.

Open All opens each bookmark and application in a folder, one after another. It skips terminal commands, templates, dividers, and applications that are no longer installed. It asks first when more than five items would open. See Limits and defaults.

Get Info

Select one item and press ⌘I, or choose Edit…. Get Info has one section for each kind of item. Only the fields that apply to the item are shown.

All items

  • Name (required).
  • Icon: choose Choose… to pick an SF Symbol or an emoji. The popover has Symbols and Emoji tabs, a search field, recent choices, and Use Default. The default is the site's icon for a bookmark, the application's icon for an application, or a standard icon for a folder, divider, or command.
  • Color (not for dividers): Red, Orange, Yellow, Green, Blue, Purple, or Gray. The colored dot appears on the icon in the menu and in this window. Click the selected color again to remove it.

Bookmarks, applications, and terminal commands (items that open something)

  • Keywords: extra words that find the item in Quick Open and Spotlight, such as "tix" for an issue tracker.
  • Open When You Log In: opens the item a few seconds after you log in. This needs Open at login turned on in Settings.
  • Notes: plain text, which can span lines. Quick Open and Spotlight show it under the name.
  • Shortcuts: see Keyboard shortcuts.

Bookmarks

  • URL (required). Save stays off while it is empty.
  • Browser: Default Browser, or one of the browsers installed on this Mac.
  • Opens In: New Tab or New Window. This applies to the browser the bookmark opens in.
  • Ask for a value when opening: turns the bookmark into a template. See Templates.
  • Link status and Last checked: shown only after a link check. Read-only. See Check links.

Applications

  • Application: the application's path, read-only.
  • Opens In: Bring Forward (the default) or New Instance.
  • Arguments: passed when the application opens, such as --profile work. Arguments always start a new instance.
  • Terminal Command: optional. When set, the item runs this command in Terminal instead of opening the application.

Terminal commands

  • Command (required). The command runs in a new Terminal window. Add only commands you trust.

Folders and dividers

  • A folder has Name, Icon, and Color. A divider has Name and Icon.

Save is one undo step named Edit. Save stays off until the required fields are filled.

Templates

A template is a bookmark whose address has a value that you type each time you open it.

A named field is plain text unless you declare it. {project} and {id:Issue number} become fields only when their names are listed in Fields, such as project, id:Issue number. Without that, Library shows the text exactly as typed.

  1. In Get Info for a bookmark, turn on Ask for a value when opening. The address gets {} at its end.
  2. Put {} where the value goes. For one value, that is enough. Library asks for the value when you open the bookmark.
  3. For several values, or a value with its own name, declare each name in Fields, such as query:Search, sort. Then write {query} in the address. Each declared name becomes a field. Library asks for all of them in one sheet.
  4. A {name} that is not declared in Fields is plain text. Only a bare {} or a declared name is a field.
  5. For a bare {}, the Prompt field sets the label. If you leave it empty, the label is "Value."

The Opens line shows the address with each field in place. Values you type are percent-encoded. A template cannot be added to the Reading List, shared, or link-checked, because its address is not complete until a value is typed.

Bulk edit

Select several rows and choose Edit… (or ⌘I). Bulk edit changes only Icon, Color, and Opens In. The bulk sheet changes only the fields you set. Each field starts at Don't Change.

  • Icon: Don't Change, Default, or Custom, then Choose… for a symbol or emoji.
  • Color: Don't Change, None, or a color. Shown only when at least one selected item can have a color. Dividers are skipped.
  • Opens In: shown when the selection has a bookmark or an application. When the selection mixes the two, the labels read "Existing" and "New." Items with no choice are skipped.

The bulk sheet cannot change names, URLs, keywords, notes, shortcuts, or templates. Use Get Info for one item at a time for those. Save stays off until you change a field. All changes apply as one undo step named Edit Items.

Reading List

Use the Reading List to save bookmarks to read later.

  1. Right-click one or more bookmarks.
  2. Choose Add to Reading List.

Items in the list appear in a Reading List section at the top, unread first, then read. Each one also stays in its folder in the library. Use the right-click menu to Mark as Read, Mark as Unread, or Remove from Reading List. Removing an item from the Reading List leaves it in your library.

Only bookmarks with a fixed address can be added. Templates, applications, folders, and terminal commands cannot.

Delete and Recently Deleted

Deleting moves items to Recently Deleted, so you can get them back. To delete, use the Delete key, Command-Delete, the toolbar's Delete button, or Delete in the right-click menu. Folders go with their contents. Undo is one step named Delete.

  • Restore puts an item back in its folder. If that folder no longer exists, the item goes to the top level. Undo is one step named Restore.
  • Delete Immediately removes the item for good. It asks for confirmation first, and it cannot be undone.
  • Pressing Delete on an item that is already in Recently Deleted asks the same question.
  • Items stay in Recently Deleted for 30 days. Library removes older items the next time it saves the library.

Find Duplicates

Choose File > Find Duplicates… to find bookmarks and applications that open the same thing.

Two bookmarks are duplicates when they have the same address and the same browser. The comparison ignores differences in the case of the scheme and host and a trailing slash, and it treats a missing https:// as https://. The path and query keep their case. Two applications are duplicates when they are the same application with the same arguments.

The sheet groups the duplicates under Same link or Same application.

  1. Select the copy to keep in each group. The first item in each group is kept unless you choose another.
  2. Choose Merge.

Merging removes the other copies. The kept item:

  • keeps its own folder and its own shortcuts;
  • takes the keywords of every copy in the group;
  • takes each shortcut of the removed copies whose key combination is not already used. A shortcut that clashes is not kept, and the summary lists it.

The summary appears in an alert titled Duplicates Merged. Undo is one step named Merge Duplicates.

Import bookmarks

Choose File > Import Bookmarks… to bring in bookmarks from Safari or Chrome.

  1. Choose the bookmarks file in the open panel:
    • Safari: Bookmarks.plist in ~/Library/Safari.
    • Chrome: the Bookmarks file in ~/Library/Application Support/Google/Chrome/Default. Press ⇧⌘G in the panel to type a path.
  2. Library adds the bookmarks in one folder, named Imported from Safari or Imported from Chrome. Folders keep their structure. Safari's Favorites Bar and Bookmarks Menu keep those names.

Entries that are not web links are skipped. Safari's Reading List and sync folders are not imported. An alert reports how many bookmarks were imported and how many entries were skipped.

The import is one undo step named Import Bookmarks.

If the file can't be read, isn't a Safari or Chrome bookmarks file, or has no web bookmarks, Library says so and changes nothing.

Check links

Choose File > Check Links to check every bookmark now.

  • Each address is checked at most once a day. An address that was checked in the last 24 hours is skipped. Up to four addresses are checked at a time.
  • Library first sends a HEAD request, which asks only for the headers. If the server refuses it, Library sends a GET request and reads up to 64 KB of the page to decide.
  • A bookmark whose page returned an error (a 4xx or 5xx code) shows a warning icon, with Broken link in its tooltip.
  • A bookmark whose site did not answer (no response, a timeout, a redirect loop, or more than five redirects) shows Unreachable link.
  • Get Info shows the result and the time of the last check.

To check once a day in the background, turn on Check links periodically in Settings > General. It is off by default. The daily check runs while Library is open.

Link checks are not undo steps.

Export and restore

Export and restore are in two places.

Export

  • File > Export Library… or Settings > General > Backup > Export….
  • The file is named Library Backup followed by the date, in JSON.
  • The backup has your bookmarks, folders, shortcuts, icons, keywords, colors, templates, and Open at Login settings.
  • Items in Recently Deleted are not exported.
  • Clipboard items are not exported. Pinned clipboard items are encrypted with a key that stays on this Mac.

Restore

  • Settings > General > Backup > Restore….
  • Library asks you to confirm Replace Library. The default button is Cancel.
  • Restoring replaces your current library. Undo restores the library you had before.
  • An item in the backup whose id is already used by an item in Recently Deleted gets a new id, so the two do not collide.
  • Restore is refused when bookmarks.json cannot be read, because the restored library could not be saved.

These keys work while the Library window is in front. Apart from ⌘N, ⇧⌘N, and ⌘I, the File menu items have no key.

Where your data is stored and whether it syncs

  • The library is kept in bookmarks.json in the .library folder in your home folder. The file is readable only by you.
  • Edits are saved about a quarter of a second after you make them.
  • Recently Deleted, the Reading List, and link check results are stored in the same file.
  • With Keep Library in iCloud Drive on, bookmarks.json is kept in iCloud Drive and syncs to your other Macs. If two Macs change the library at the same time, Library asks which version to keep. Review lists each difference so you can choose for each one.
  • Open counts and the time each item was last opened are stored in preferences on this Mac and do not sync. They drive Most Used and Recently Opened.

Limits and defaults

  • Undo uses the Library window's undo history. Edits made before the window has been opened in this session are not undoable. Changes that come from another Mac or from iCloud clear the undo history.
  • Recently Deleted keeps items for 30 days.
  • Open All asks before opening more than five items. This threshold is fixed at five. There is no setting for it.
  • Open All skips terminal commands, templates, dividers, and applications that are no longer installed. It opens the rest one after another, about 150 milliseconds apart.
  • Link check requests each address at most once per 24 hours, with up to four addresses at a time, and gives up on a request after 10 seconds.
  • Most Used and Recently Opened use the usage recorded on this Mac.
  • The window size and position are remembered.

Settings that change the manager

  • Settings > General > Name new bookmarks from their pages: off by default. When it is on, a new bookmark takes its page's title.
  • Settings > General > Check links periodically: off by default.
  • Settings > General > Keep Library in iCloud Drive: off by default.
  • Settings > General > Backup: Export and Restore.
  • Settings > General > Open at login must be on for Open When You Log In on an item to do anything.

Caveats

  • Terminal commands marked Open When You Log In run in Terminal when Library opens at login. They run without a confirmation. See Keyboard shortcuts for the other places a command runs.
  • Bulk edit does not change names, addresses, keywords, notes, or shortcuts.
  • Sorting is not saved between launches.
  • The Library menu item is Edit Library…, and the window is titled "Library."

Color items

A color is a dot that helps you sort items at a glance. Use colors to organize your library, not to show status. Library has seven colors: red, orange, yellow, green, blue, purple, and gray.

  • Set a color. Select an item, press ⌘I to open Get Info, and choose a dot under Color. Choose the same dot again to clear it.
  • Set a color on several items. Select them and edit them together. The sheet has a Color menu. Choose None to clear the color on all of them.
  • See the color. The dot appears on the item's icon in the menu bar, in Quick Open, and in the Library window.
  • Find colored items. Type the color's name in Quick Open, such as blue. Spotlight finds them by color name too.

The color is saved with the item in bookmarks.json. If you keep your library in iCloud Drive, the color syncs to your other Macs with the item.

The Library menu

Click the Library icon in the menu bar to open the menu. To open it at the pointer, press the Show Library Menu shortcut. Settings > Shortcuts > Library menu opens decides where it appears.

  • Update Available. Appears at the top when a newer version exists. Choose it to see the update options. See Stay up to date.
  • Your items. Bookmarks, apps, terminal commands, folders, and dividers, in the order you set in Edit Library. Folders open as submenus.
  • Frequently Used. Up to five top-level items you have opened at least twice, most opened first.
  • Reading List. Your bookmarks in the Reading List. Unread bookmarks show first.
  • Clipboard. Your latest copies. Choose one to copy it again. When the history is empty, it says No Clipboard History. Clear History removes the unpinned history.
  • Paste Queue. Appears when the queue has items. Paste Next pastes the next one, and Clear Queue empties it.
  • Lock Pinned Items. Appears only when the Touch ID or password lock is on. It is dimmed while the pinned items are already locked.
  • Edit Library…, Settings…, Open at Login, Check for Updates…, About Library, and Quit Library.

A folder with nothing in it shows Empty. Open All opens the bookmarks and apps in the folder, including those in its subfolders, one after another. It is dimmed when none of them can be opened.

Add notes

Write a note on any item in Get Info. Quick Open shows the note under the item's name. Spotlight includes it in the description. Notes are plain text and stay in your library.

Library has two kinds of shortcut:

  • Global shortcuts work in every app. They open the Library menu, Quick Open, the clipboard menu, and the link you copied last.
  • Item shortcuts open one bookmark, application, or terminal command from anywhere. You set them in Get Info.

Both kinds can be a key combination, a modified click, a scroll, a pinch, a swipe, or a hot corner.

Defaults on first launch

The first time a version with these defaults runs, the Library menu and Quick Open get their defaults if they have none, and the clipboard menu gets Control-Command-V. After that first run, clearing a shortcut sticks.

Change or clear a global shortcut

  1. Open Settings > Shortcuts.
  2. Click the shortcut field. It reads Record Shortcut and then Press a shortcut…, with an outline around it.
  3. Press the keys you want. The shortcut is saved as soon as you press it.

To cancel without changing anything, press Escape or click anywhere else.

To clear a shortcut, click the … button next to the field and choose Clear. The … menu also sets a hot corner. Clear is available only in Settings.

To go back to the defaults, choose Restore Defaults. It sets the Library menu, Quick Open, and the clipboard menu back to their defaults. It does not change Open Copied Link.

Library menu opens sets where the Library menu appears:

  • At the Pointer (the default): the menu opens where the pointer is.
  • From the Menu Bar: the menu opens from the menu bar icon.

Shortcuts on an item

Set item shortcuts in Get Info, in the Shortcuts section. The section appears for bookmarks, applications, and terminal commands. It does not appear for folders or dividers.

  1. Select the item and press ⌘I.
  2. Choose Add Shortcut. A new row starts recording.
  3. Press the keys, click with a modifier, scroll, pinch, swipe, or choose a hot corner from the … menu.
  4. Repeat to add more shortcuts. An item can have several.
  5. Choose the minus button to remove a shortcut.

For a bookmark or an application, each shortcut has its own Opens In setting:

  • Bookmarks: New Tab or New Window.
  • Applications: Bring Forward or New Instance.

Pressing a shortcut opens the item. A shortcut for a terminal command runs the command in Terminal. See Terminal commands run without a confirmation.

Shortcuts on an item are saved with the item. They sync with the rest of your library when Keep Library in iCloud Drive is on. Global shortcuts are saved on this Mac only.

Conflicts

A shortcut can be in use by macOS or by another app. Library cannot always tell.

  • Key combinations: if the system refuses a key combination, Library shows an orange warning triangle with the tooltip In use by another app. You see it next to the global shortcut in Settings > Shortcuts, and in the Shortcut column in Edit Library next to the item.
  • Control-Space can conflict with the macOS input source shortcut. The Settings page says so.
  • Modified clicks, scrolls, pinches, swipes, and hot corners are not checked against other apps. If another app uses the same gesture, the result depends on which app gets the event first.
  • Library does not check for two of its own shortcuts that use the same keys before it registers them. If the system refuses the second one, it is flagged the same way as any other conflict.

To fix a conflict, record a different combination.

Hot corners

A hot corner runs a shortcut when the pointer reaches a corner of a screen.

  1. In a shortcut field, open the … menu.
  2. Choose Hot Corner, then one of Top Left Corner, Top Right Corner, Bottom Left Corner, or Bottom Right Corner.

A hot corner fires when the pointer reaches a spot within about two points of the corner, and only when no modifier key is held. It fires again only after the pointer has moved about 40 points away from the corner. Hot corners need no permission.

Accessibility

Click, scroll, pinch, and swipe shortcuts need Accessibility access. Key combinations and hot corners do not.

To turn it on, open System Settings > Privacy & Security > Accessibility and allow Library. Library also shows a Grant Access… button in Get Info and an Allow… button in Settings when access is missing.

Until access is granted, those shortcuts do nothing. Library checks again every few seconds and starts them when access arrives.

When Library handles a click, scroll, pinch, or swipe shortcut, it takes the event. The app under the pointer does not receive it. Button shortcuts run when the button is released, so a menu does not close under a held button.

Scroll shortcuts run once per scroll gesture. A pinch runs once it passes a small threshold. A swipe runs once per swipe.

Terminal commands run without a confirmation

A terminal command runs in a new Terminal window whenever its shortcut is pressed, or when it is opened from Spotlight, or when it opens at login. It runs right away in each of these cases. Library does not ask first. This is how it works today. Whether it should ask first has not been decided. The URL scheme and the Shortcuts app are different: the URL scheme never runs a command, and the Shortcuts app asks first.

Only add commands you trust, and use a shortcut that is hard to press by accident.

Storage and sync

  • Global shortcuts are saved in preferences on this Mac and do not sync.
  • Item shortcuts are saved in bookmarks.json, with the item. They sync when the library is in iCloud Drive.
  • Library reads the shortcuts again whenever they change. You do not need to restart the app.

Limits and defaults

  • Four hot corners, each set from the … menu.
  • Restore Defaults does not change item shortcuts or Open Copied Link.
  • Escape cancels a recording only when no modifier key is held.

Work with other apps

Library works with other apps in four ways:

  • the library:// address, which other apps and web pages can open;
  • Add to Library in the Services menu;
  • Spotlight, which finds your items in any search;
  • Shortcuts, which can run Library actions in automations.

URL scheme

Library handles links that start with library://. A link never opens the Edit Library window. It does one of the following three things.

LinkWhat it does
library://open?name=NAMEOpens the bookmark or application named NAME
library://open?name=NAME&value=VALUEOpens the bookmark or application named NAME, and fills its template with VALUE
library://menuShows the Library menu
library://searchOpens Quick Open

Examples:

  • library://open?name=Jira
  • library://open?name=Jira&value=ABC-123
  • library://open?name=Team%20Board
  • library://menu
  • library://search

How the name is matched

  • The name must match an item's name exactly, ignoring case. Library does not match part of a name.
  • Library looks at bookmarks, applications, and dividers, in the order they appear in the library. It uses the first item that matches.
  • Folders are never matched.
  • Terminal commands are never matched, so a link can never run one.
  • Items in Recently Deleted are not matched.
  • A divider with the same name as a bookmark can be matched first, and then nothing opens. Give dividers names that differ from your bookmarks.
  • If nothing matches, the link does nothing and shows no message.

How the value is used

  • If the bookmark has exactly one field in its address, value fills it, and Library does not ask for a value.
  • If the bookmark has more than one field, Library asks for all of them in one sheet, and value is ignored.
  • If the bookmark is a template and no value is given, Library asks for the value.
  • Spaces in a value must be encoded as %20.
  • A value is used as typed. Nothing asks you to confirm it.

What the scheme does not do

  • It does not open commands, so a web page cannot run a terminal command with it.
  • It does not show a window, and it does not change your library.
  • Unknown hosts, such as library://something, and any other parameters are ignored.

Anything that can open a library:// link can open any bookmark or application in your library by its name, with no confirmation. A link can also fill a template's single field with a value, with no prompt. Give your items names you are comfortable with other apps and web pages using.

Services

Library adds two items to the Services menu: Add to Library. They appear in the Services menu of most apps, and in the Finder's right-click Services menu.

Add a link from any app

  1. Select a web address in an app, such as a page address in a document or a message.
  2. Choose Services > Add to Library.
  3. The selection must be one web address that starts with http:// or https://. A bare domain, such as example.com, is not accepted here, though Quick Open accepts it.
  4. The selection can be up to 4,096 characters. Spaces and line breaks around it are ignored.
  5. The new bookmark goes at the top level of the library. It is named after the address's host, and its address is the text you selected.
  6. If the selection is not a web address, Library shows the message "The selection is not a web link."
  7. Library does not check for duplicates, so adding the same address twice gives two bookmarks.
  8. If Name new bookmarks from their pages is on in Settings, Library then reads the page's title and uses it as the name.

Add applications and folders from the Finder

  1. Select one or more applications or folders in the Finder.
  2. Choose Services > Add to Library.
  3. Each application is added by its name and path. Each folder is added as a link to the folder. Choosing a folder opens it in the Finder.
  4. Applications and folders already in the library are skipped.
  5. Other files in the selection are ignored. If nothing in the selection can be added, Library shows the message "Only applications and folders that aren't already in your library can be added."
  6. The additions go at the top level and are one undo step named Add to Library.

If the Services items do not appear

Log out and back in, or run /System/Library/CoreServices/pbs -update in Terminal. Library asks macOS to refresh its services each time it starts.

Spotlight

Library adds its items to the Spotlight index, so Spotlight can find them.

What is indexed

  • Every bookmark, application, terminal command, and template that opens something.
  • Not folders, dividers, or items in Recently Deleted.

What Spotlight sees for each item

  • Title: the item's name.
  • Description: the address, command, or application path, with the item's note on the line below it.
  • Keywords: the item's keywords and its color name, such as "red."

When the index updates

  • Library waits about 0.8 seconds after you change the library, then updates Spotlight.
  • It only changes Spotlight when something Spotlight shows has changed. Renaming an item, editing its keywords, note, or address, or deleting it all count.
  • Library keeps its entries in one search domain called "library." It also removes an older domain called "bookmarks" when it updates.

Opening a result

Opening a Spotlight result runs the item the same way the Library menu does:

  • a bookmark opens in its browser;
  • an application opens or comes to the front;
  • a template asks for its value first;
  • a terminal command runs in Terminal right away, without a confirmation.

There is no setting that turns Spotlight indexing off. Delete an item, or remove its keywords and note, to take it out of the index.

The index is stored by macOS on this Mac. Library does not send it anywhere.

Shortcuts

Library defines actions for the Shortcuts app, so you can run them in automations.

Build note: these actions appear in Shortcuts only in a build that includes App Intents metadata. Xcode generates that metadata. The build script, ./build.sh, does not produce it. ./install.sh and the release zip use the same script, so they do not include it either. The actions below describe what the code provides. Until a build includes the metadata, none of them appears in Shortcuts.

Details for each action

Open Library Item works with bookmarks and applications only. It does not open a terminal command. If the item is no longer in the library, the action fails with "“NAME” is no longer in Library." Value fills a template with one field. If the template has several fields, or no value is given, Library asks for the values in its own dialog.

Search Library finds bookmarks and applications the way Quick Open does, matching names, keywords, and addresses. It does not return terminal commands. The result can be used by later actions in the same shortcut.

Add Bookmark to Library accepts any link with a host, including links that use an app's own scheme, such as obsidian://..., and bare domains such as example.com. It does not accept only web addresses as Services does. The bookmark is named after the host. If the link is not valid, the action fails with "That is not a web link." It does not check for duplicates.

Add Application to Library needs an application file. Any other file fails with "Choose an application (.app) file." It does not check for duplicates.

Frequently Used Library Items returns the bookmarks and applications you have opened at least twice, most used first, up to five.

Open Clipboard Link opens the first web link on the clipboard. If the clipboard has no link, Library beeps and the shortcut continues.

Copy Latest Clip copies the newest clipboard item that is not a locked pinned item. It does not paste into another app. If the history is empty, the action fails with "The clipboard history is empty."

Search Clipboard History returns the text of up to 20 items that contain every word of the search. Locked pinned items are never returned. An item with no text returns its title. Anything the shortcut returns can be passed to other actions, including actions in other apps.

Show Quick Open and Show Library Menu open Library before they run.

Run Terminal Command shows a dialog before anything runs. The dialog reads: "Run “NAME” in Terminal? The command is:" followed by the full command. If you decline, the shortcut stops and nothing runs. After you confirm, Library checks that the command is still the same. If it changed while the dialog was open, nothing runs and the action fails. Library asks every time. There is no option to stop asking.

  • Only Run Terminal Command asks you to confirm an action. Open Library Item asks for a template value only when none was given.

Stay up to date

While Library runs, it checks GitHub for a new release every hour. It also checks at launch if the last check was an hour or more ago.

When a newer version exists, one item appears at the top of the menu. Nothing pops up. To turn checks off, use Settings > General. Choose Check for Updates… at any time. It offers the newer version. If you choose to install it, Library opens Terminal, clones the release, and runs its installer. It does not install silently. See what is sent.

Settings

Press ⌘, to open Settings. It has three tabs: General, Shortcuts, and Clipboard.

General

  • Open at login starts Library when you log in.
  • Name new bookmarks from their pages. Library reads each new bookmark's title from its page. Until the title arrives, or when the page has none, the bookmark is named after its host. Off by default.
  • Keep Library in iCloud Drive. See iCloud Drive. Off by default.
  • Check for updates automatically. On by default. See Stay up to date.
  • Check links periodically. Off by default. See Check links.
  • Export… and Restore… save and restore your library. See Back up and restore.
  • Show… opens the welcome screen, which explains Library, lists your shortcuts, and asks for access.
  • Remove tracking parameters when copying links. On by default. Library removes tracking codes such as utm_source, fbclid, and gclid from a link you copy. The rest of the link stays the same, and the saved link is not changed.

Shortcuts

  • Show Library Menu, Show Quick Open, Show Clipboard Menu, and Open Copied Link. Click a field and press the new keys. These work in every app. Open Copied Link opens the web link you last copied. A beep means the clipboard has no link.
  • Library menu opens: At the Pointer or From the Menu Bar.
  • Allow… asks for Accessibility access. Clicks, scrolls, pinches, swipes, and suggesting a selected link need it.
  • Restore Defaults puts the shortcuts back to their defaults: Control and right-click for the Library menu, Control-Space for Quick Open, and Control-Command-V for the clipboard menu. macOS may use Control-Space to switch input sources.

Clipboard

  • Keep clipboard history. On by default. Turn it off to stop recording new copies.
  • Paste into text fields. On by default. If a text field has the keyboard, choosing an item pastes it. Otherwise it copies. This needs Accessibility access.
  • Play copied GIFs. Off by default. See What is sent.
  • Clear History removes the unpinned history.
  • Keep clipboard history across restarts. Off by default. See Keep what you copy.
  • Put the Latest Item on the Clipboard When Library Opens. Off by default. The newest saved item is copied when Library opens, so you can paste it right away. A password copied before a restart could be pasted by someone else at this Mac.
  • Require Touch ID or password to show pinned items. Off by default. See Touch ID or password lock.

Permissions

  • Keyboard shortcuts, hot corners, Quick Open, and the menus don't need any permission.
  • Click, scroll, pinch, and swipe shortcuts, pasting into text fields, and suggesting a selected link need Accessibility access. Turn it on in System Settings > Privacy & Security > Accessibility. Library reads your selection only when you open one of its menus, and it doesn't keep it.

Help menu

The Help menu is in the menu bar at the top of the screen.

  • Library Help opens the Library README on GitHub.
  • Keyboard Shortcuts opens the shortcuts section of the README on GitHub.
  • Welcome Tour… opens the welcome screen. It is the same as Settings > General > Show….
  • Report an Issue… opens a new issue on GitHub.

The GitHub links open in your default browser. Library does not load them.

Troubleshooting

  • A shortcut doesn't work. Another app may use the same keys. Check Settings > Shortcuts. Control-Space can conflict with the macOS input source shortcut.
  • Clicks stop working after a macOS update. Remove Library from Accessibility, then add it again.
  • Open at Login does nothing. Move Library.app to /Applications first. The login item remembers where the app is.
  • Services don't appear. Log out and back in, or run /System/Library/CoreServices/pbs -update.
