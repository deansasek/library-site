Get started

Install Library first, then follow the first steps in Install.

Open anything

Bookmarks, apps, folders, and terminal commands open from the menu bar, a keyboard shortcut, or Spotlight. To open an item the other way, hold Option while you click it.

  • Bookmarks open in a new tab or a new window.
  • Apps come to the front. To start a new copy, add a launch argument, such as --profile work.
  • Terminal commands run in a login shell in a new Terminal window. Add only commands you trust.
  • Folders open as submenus. Choose Open All in a folder to open its bookmarks and apps, one after another. Library skips dividers, terminal commands, templates, and apps that are no longer installed. It asks first when more than five items would open.

Quick Open

Quick Open is a search box that floats over your screen. It searches your library, your clipboard history, and your snippets, and it runs the result you choose.

Open Quick Open

  1. Press Control-Space. This is the default shortcut.
  2. Type to search. The search field has the keyboard as soon as Quick Open opens.
  3. Press Return, or click a row, to run it. Quick Open closes.

Press the same shortcut again to close Quick Open without choosing anything. Quick Open also opens with the library://search address.

Quick Open appears centered on the screen under the pointer. It stays in place while you type. It appears over full-screen apps and on every Space.

To change the shortcut, go to Settings > Shortcuts and change Show Quick Open. Control-Space can conflict with the macOS input source shortcut. If it does, pick another key combination.

Search

Quick Open splits your text into words. Each word must match something about the item, and every word must match for the item to appear.

Library items and snippets are scored for each word:

MatchScore
The start of the name, or the start of a keyword4
Anywhere inside the name3
Target, folder, or keywords (including the color)2
The letters in order inside the name, with others between them1

An item's score is the sum of its word scores. Higher scores come first. Items with the same score are ordered by how often you have opened them, most first. Items you have not opened keep their order in the library.

Keywords, the item's color, and the folder name are all searched. Typing red finds items you gave the red color.

What appears with an empty search

With the search field empty, Quick Open shows, in order:

  1. Suggested: the link or app on the clipboard, or a link selected in the app in front, when it is not in your library yet. See Add a suggested link or app.
  2. Frequently Used: up to five items you have opened at least twice.
  3. The whole library, in the same order as the Library menu.
  4. Clipboard: the five first clipboard items. Pinned items come first.

What appears with a search

With text in the search field, results appear in these groups, each with its own heading:

  • Top Hit: the first result. Return runs it.
  • Library: matching items.
  • Clipboard: up to eight matching clipboard items, pinned items first, then newest first.
  • Snippets: matching snippets.
  • Suggestions: a web address you typed, or a suggested link or app.

Clipboard matches must contain every word, ignoring case. They are not ranked by score.

Web addresses

If the search text is a web address, Quick Open adds two rows:

  • Open followed by the host, for example Open example.com.
  • Add "example.com" to Library.

A web address has no spaces. It is either a full address with ://, or a host name with a dot and a top-level domain of at least two letters, such as example.com/path. localhost is not treated as a web address.

Add a suggested link or app

When the clipboard holds a web link or an application that is not in your library, Quick Open offers to add it. It is listed under Suggested with an empty search. It is also listed when the search is at least two characters long and is part of the words "add to library", such as ad or to li.

A link selected in the app in front is used first, if Quick Open can read it. Choosing the suggestion adds it to the library. If the page can be read, Library names the new bookmark from its title when Name new bookmarks from their pages is on.

Search only one app's copies

Type from and the name of an app to see only the clipboard items you copied while that app was in front. For example, from Safari shows Safari copies. Add words after the app name to search those copies, such as from Safari invoice.

The name must match an app that appears in your clipboard history, ignoring case. When two apps match, the longer name wins. When the search starts with from <app>, the library is not searched.

The pointer also works. Moving the pointer over a row selects it, once the pointer has moved. Clicking a row runs it. Right-clicking shows the same actions as Tab.

Option-Return

For a library item that can open two ways, Option-Return does the opposite of the item's usual setting:

  • A web bookmark opens in a new tab, or in a new window.
  • An app is brought forward, or a new instance is started.

The labels in the actions list name the two ways. For clipboard items and snippets, Option-Return does the same as Return.

Option-click does not change how a row opens in Quick Open. Use Option-Return.

Space

Space previews the selected clipboard item in Quick Look. Press Space again, or Escape, to close the preview.

Space types a space when the selected row is not a clipboard item, or when the clipboard item has nothing to preview. This is true even with an empty search.

Actions

Press Tab, or right-click a row, to see its actions. The actions depend on the row.

Library item (a bookmark, app, command, or folder item):

  • Open, and the other way to open the item, where it applies.
  • Copy Link, for a bookmark.
  • Copy Clean Link, for a bookmark. It removes tracking parameters such as utm_source, fbclid, and gclid. The saved link is not changed.
  • Copy as Markdown Link, for a bookmark. Not offered for templates.
  • Copy Command, for a terminal command.
  • Copy Path and Show in Finder, for an app.
  • Add to Reading List, or Mark as Read, Mark as Unread, and Remove from Reading List, for a bookmark in the Reading List.

Clipboard item: see Clipboard. The actions include Copy or Paste, Copy as Plain Text, Copy as, Quick Look, Pin or Unpin, Add to Paste Queue, Add to Library, and Delete.

Typed web address: Copy Clean Link.

Snippet: Copy and Edit.

Choosing an action runs it and closes Quick Open. Choosing Copy as… or another submenu lists its choices in place of the actions.

Preview

The right side of Quick Open shows the selected row in full. It is 280 points wide.

  • Clipboard text: the first 4,000 characters, selectable, with the source app, time, and size.
  • Picture: the picture. A GIF plays.
  • Files: each file's name and icon.
  • Other copies: the number of formats.
  • Library item: its name, icon, and link, command, or path. Its folder appears under it.
  • Snippet: its name and the first 4,000 characters of its text.
  • Locked pinned item: the words Pinned Item, and a Show Pinned Item button. See Clipboard.

Clicking into the preview does not close Quick Open.

Keywords, colors, and notes on an item also affect what Quick Open shows. Notes appear under the item's name in the list.

Limits

  • Clipboard matches in a search: eight.
  • Clipboard items with an empty search: five.
  • Frequently Used: five items, each opened at least twice.
  • Text in a clipboard item is searched up to its first 100,000 characters.
  • The preview shows the first 4,000 characters of text.
  • Each row is 42 points tall. The list shows about seven or eight rows at once and scrolls for the rest.

What it stores and whether it syncs

Quick Open stores nothing of its own. It reads:

  • The library, which is in iCloud Drive when Keep Library in iCloud Drive is on.
  • Clipboard history, which stays on this Mac. See Clipboard.
  • Snippets.
  • Open counts, which set the Frequently Used list, are kept on this Mac.

Notes

  • Quick Open closes when another app comes to the front, when the Spotlight search opens, or when you click elsewhere. It stays open while the Quick Look preview has the keyboard, and while the Touch ID or password prompt is up.
  • A row can be dragged into another app. A clipboard image, file, link, or text is dropped as that type, and Quick Open closes after the drop.

Clipboard

Library keeps a history of what you copy. You can copy an item back, paste it into a text field, pin the items you keep, and queue several items to paste in order. The history is reached from the clipboard menu, from the Clipboard submenu in the Library menu, and from Quick Open.

What it records

Library records each copy with every format it was copied in, so copying an item back loses nothing. It records:

  • Text, and links. A link is text that is a web address.
  • Images. A copied image is kept in one format, PNG when there is one.
  • Files, by name and icon.
  • Any other copy, which shows as Clipboard Item.

Library checks the clipboard about twice a second. A copy appears in the history a moment after it is made.

Copying the same thing again does not add a second entry. The existing entry moves to the top, and keeps its pin.

Library does not record a copy when:

  • The copy is marked as private by a password manager or a system field.
  • The copy is made while a password manager is in front. The apps are 1Password, Bitwarden, KeePassXC, LastPass, Dashlane, Keychain Access, and Passwords.
  • The copy is larger than 25 MB.

Pin an item

Pinned items stay in the history after you quit, and they are never removed by the limits below.

  1. In Quick Open, find the item, and press Tab.
  2. Choose Pin.
  3. To remove the pin, press Tab on the item again and choose Unpin.

Pins are set in Quick Open only. Pinned items show first in the clipboard menu, under Pinned, and first in Quick Open.

Open the clipboard menu

  1. Press Control-Command-V. The menu opens at the pointer.
  2. Choose an item to copy it back, or press a number key from 1 to 9 to choose one of the first nine items.
  3. Hold Option over a rich-text item. Its entry changes to Copy as Plain Text, and choosing it copies the text without formatting.

The menu lists pinned items under Pinned and the 20 most recent other items under Recent. It has Clear History at the bottom. When a text field has the keyboard, the headers say Paste Pinned and Paste Recent, and choosing an item pastes it. See Paste into text fields.

If the clipboard or the selected text in the app in front holds a link or app that is not in your library, the menu starts with a row that adds it.

To change the shortcut, go to Settings > Shortcuts and change Show Clipboard Menu.

The Clipboard submenu in the Library menu

The Clipboard submenu in the Library menu lists the ten first items, pinned items first. Choosing one copies it. It never pastes. It has Clear History, and the paste queue when the queue has items.

Paste into text fields

When Paste into text fields is on, choosing an item from Quick Open or the clipboard menu pastes it, if a text field had the keyboard when the menu or Quick Open opened. Otherwise it copies the item.

Library checks for a text field as the menu or Quick Open opens. When you then choose an item, Library presses Command-V in the app in front, a moment later.

This needs Accessibility access. Without it, choosing an item copies it.

Paste queue

Use the paste queue to paste several items in order.

  1. In Quick Open, find an item, press Tab, and choose Add to Paste Queue.
  2. Repeat for each item. The queue lists them in order in the clipboard menu.
  3. Choose Paste Next in the clipboard menu. Library copies the first item and removes it from the queue.
  4. Press Command-V in the app you are working in. Repeat from step 3 for the next item.

Clear Queue removes every item from the queue. The queue is kept in memory only, so it is empty when Library starts.

Choosing Paste Next copies the item. It does not paste it into the app for you.

Copy as

Copy as turns a text item into a new clipboard entry. The original stays in the history as it was.

  1. In Quick Open, find a text item, press Tab, and choose Copy as….
  2. Choose one of the options:
    • Plain Text copies the text without formatting.
    • Trimmed Whitespace removes spaces and line breaks at both ends.
    • Lowercase and Uppercase change the case.
    • Joined Lines turns each line break into a space.
    • Smart Punctuation turns straight quotes into curly quotes, ' into ’, -- into an em dash, and ... into an ellipsis. A quote opens when it comes first or follows a space, a bracket, or a dash. An apostrophe before a year, such as '90s, becomes ’90s.

Copy as is offered for text items only. Links and pictures do not have it.

Markdown links

Use Markdown links to paste a title and its address in a document.

  1. In Quick Open, find a bookmark, or a copied link, press Tab, and choose Copy as Markdown Link.
  2. Paste into a Markdown document. The result is [Title](address).

The title is the bookmark's name, or the copied link's host. Characters that have a meaning in Markdown are escaped. Spaces and parentheses in the address are percent-encoded. In a rich-text field, the title pastes as a link.

Templates do not offer this action.

Filter by the app you copied from

Each copy records the app that was in front when you copied it. You can list only the copies made in one app.

  1. Open Quick Open.
  2. Type from and the app's name, such as from Safari.
  3. Add words after the name to search those copies, such as from Safari invoice.

The name matches an app in your history, ignoring case. Copies made while Library itself was in front have no app name, so they do not appear in any app filter.

Quick Look and the Space key

Quick Look shows a clipboard item in the system preview panel.

  • In Quick Open, select a clipboard item and press Space. Press Space again, or Escape, to close the preview.
  • In Quick Open, press Tab, and choose Quick Look.

Text and pictures are shown from a temporary copy. Files are shown where they are. Items with nothing to show, such as a format Library does not display, cannot be previewed.

The temporary copies are in a private folder in the system temporary folder. They are deleted when the preview closes. Any left by a quit or a crash are deleted the next time Library starts.

Clicking into the preview does not close Quick Open.

Actions for text

For a text item, Quick Open's Tab actions also include three actions that work on the text. Each appears only when the text has the matching thing in it:

  • Open in Maps opens an address in Apple Maps.
  • Copy Phone Number copies the number with its digits and plus sign only.
  • Add to Calendar opens Calendar's add-event sheet for a date or time. The event's title is the first line of the text. An event with no length lasts one hour.

Library finds these on this Mac. It looks at the first 10,000 characters of the text.

Play copied GIFs

Browsers copy a still picture when you copy an animated GIF. With Play copied GIFs on, Library downloads the original GIF from the page, so it plays in the list and the preview.

  • The setting is off by default.
  • It applies to copies made while it is on. It does not download GIFs for copies you made earlier.
  • Library asks the page's server for the GIF file only. It sends no cookies, and it stops after 10 seconds or 25 MB.
  • Animated GIFs show a small animated icon in the list.

Turn it on in Settings > Clipboard.

Lock pinned items

The lock asks for Touch ID or your Mac password before pinned items are shown or copied.

  1. Open Settings > Clipboard.
  2. Turn on Require Touch ID or password to show pinned items.

Library will not turn the lock on when your Mac has neither Touch ID nor a password. Add a password in System Settings, then turn it on again.

With the lock on:

  • A locked pinned item shows a lock icon and the words Pinned Item, in the list, the menu, and the queue.
  • Search does not find a locked pinned item.
  • Copying, Quick Look, Show Pinned Item, Add to Library, and Paste Next ask you to authenticate first. If you cancel, nothing changes, and the item stays locked.
  • Pin, Unpin, Delete, and Add to Paste Queue do not ask, and they do not show the item's text.

After you authenticate, the items stay unlocked until one of these happens:

  • You choose Lock Pinned Items in the Library menu. The item appears only when the lock is on, and it is dimmed while the items are already locked.
  • Your Mac goes to sleep.
  • You turn the setting on. Turning it on always locks the items.
  • Library quits. The next launch starts locked.

Keep clipboard history across restarts

By default, unpinned history is kept in memory and is gone when Library quits. Pinned items are always kept.

To keep unpinned history:

  1. Open Settings > Clipboard.
  2. Turn on Keep clipboard history across restarts.

With this on:

  • The unpinned history is saved to a file when a copy is made, about a second after it.
  • Copies from password managers and copies marked private are never saved.
  • Images over 5 MB are not saved. Other items are.
  • Turning the setting off deletes the saved history file.

To copy the newest saved item to the clipboard when Library opens, turn on Put the Latest Item on the Clipboard When Library Opens. It needs the setting above. It does nothing when you have copied something since Library opened. A password copied before a restart could be pasted by someone else at this Mac.

Limits

  • Unpinned items: the 50 most recent. Pinned items are not counted.
  • Memory: the history holds up to 200 MB in total, including pinned items. When the total is over, the oldest unpinned items are removed first.
  • Each copy: up to 25 MB. A larger copy is not recorded.
  • Search: the first 100,000 characters of each text item are searched.
  • Saved images: 5 MB each, when history is kept across restarts.
  • Clipboard menu: the first nine items have number keys. The menu lists pinned items, then up to 20 recent items.

What it stores and whether it syncs

  • Pinned items are saved in ~/.library/clipboard.json.
  • Unpinned history is saved in ~/.library/clipboard-history.json, only when Keep clipboard history across restarts is on.
  • Both files are encrypted with a key kept in your login Keychain, on this Mac only.
  • The folder is readable only by you. Each file is readable only by you.
  • If a file cannot be read, it is moved aside, to clipboard-damaged.bin or clipboard-history-damaged.bin, and is not deleted.

Clipboard history does not sync. It stays on this Mac, even with Keep Library in iCloud Drive on. Export does not include clipboard items.

Caveats

  • Turning off Keep clipboard history stops recording. It does not clear what is already in the history.
  • A copy is recorded about half a second after you make it.
  • Hold Option for Copy as Plain Text only works on rich-text items in the clipboard menu. Other items do not offer that choice.
  • The paste queue is cleared when Library quits.
  • Quick Look temporary copies are removed when Library starts, so a preview left open by a crash does not leave its copy behind.

Save snippets

Save text you type often, such as an address or a standard reply, as a snippet. To add one, choose File > New Snippet…, or click Snippets in the Library window.

To copy a snippet, type its name or a keyword in Quick Open, then press Return.

Organize your library

Choose Edit Library… to manage everything in one window.

  • Add items with the + menu. You can also drag an app or a link into the window.
  • Drag rows to reorder them, or to move them into a folder.
  • Select several rows to move, reorder, or edit them together. A bulk change is one undo step.
  • Deleted items go to Recently Deleted. They are removed for good after 30 days.
  • Right-click a row to open, edit or rename, move, share, or delete it. An app can also be shown in Finder.
  • To merge duplicate bookmarks, choose File > Find Duplicates….
  • To import bookmarks from Safari or Chrome, choose File > Import Bookmarks…. They go into one folder. Press ⌘Z to undo the import.
  • To export or restore your whole library, use Settings > General.

Press ⌘Z to undo and ⇧⌘Z to redo.

Edit an item

Select an item and press ⌘I. You can also choose Edit… from the toolbar or a right-click menu.

  • Name and icon. Pick an SF Symbol or an emoji, or keep the site's favicon or the app's icon.
  • URL or Terminal Command, how a click opens it, and which browser to use.
  • Keywords help Quick Open and Spotlight find the item.
  • Color adds a dot to the item. See Color items.
  • Shortcuts can be added to any item.
  • Open When You Log In opens the item a few seconds after you log in.

Color items

A color is a dot that helps you sort items at a glance. Use colors to organize your library, not to show status. Library has seven colors: red, orange, yellow, green, blue, purple, and gray.

  • Set a color. Select an item, press ⌘I to open Get Info, and choose a dot under Color. Choose the same dot again to clear it.
  • Set a color on several items. Select them and edit them together. The sheet has a Color menu. Choose None to clear the color on all of them.
  • See the color. The dot appears on the item's icon in the menu bar, in Quick Open, and in the Library window.
  • Find colored items. Type the color's name in Quick Open, such as blue. Spotlight finds them by color name too.

The color is saved with the item in bookmarks.json. If you keep your library in iCloud Drive, the color syncs to your other Macs with the item.

The Library menu

Click the Library icon in the menu bar to open the menu. To open it at the pointer, press the Show Library Menu shortcut. Settings > Shortcuts > Library menu opens decides where it appears.

  • Update Available. Appears at the top when a newer version exists. Choose it to see the update options. See Stay up to date.
  • Your items. Bookmarks, apps, terminal commands, folders, and dividers, in the order you set in Edit Library. Folders open as submenus.
  • Frequently Used. Up to five top-level items you have opened at least twice, most opened first.
  • Reading List. Your bookmarks in the Reading List. Unread bookmarks show first.
  • Clipboard. Your latest copies. Choose one to copy it again. When the history is empty, it says No Clipboard History. Clear History removes the unpinned history.
  • Paste Queue. Appears when the queue has items. Paste Next pastes the next one, and Clear Queue empties it.
  • Lock Pinned Items. Appears only when the Touch ID or password lock is on. It is dimmed while the pinned items are already locked.
  • Edit Library…, Settings…, Open at Login, Check for Updates…, About Library, and Quit Library.

A folder with nothing in it shows Empty. Open All opens the bookmarks and apps in the folder, including those in its subfolders, one after another. It is dimmed when none of them can be opened.

Add notes

Write a note on any item in Get Info. Quick Open shows the note under the item's name. Spotlight includes it in the description. Notes are plain text and stay in your library.

Use templates

Put {} in a URL where a value goes. Library asks for the value when you open the bookmark.

To name several values, use {project} or {id:Issue number}. Library asks for all of them in one sheet.

Read later

Add a bookmark to the Reading List from its right-click menu, or press Tab in Quick Open.

  • The list appears in the Library window and in the menu. Unread bookmarks show first.
  • Mark a bookmark as read or unread, or remove it from the list.
  • Removing a bookmark from the list keeps it in your library.

Shortcuts

A shortcut can be a key combination, a modified click, a scroll, a pinch, a swipe, or a hot corner. Shortcut keys need Control, Option, or Command. An item can have several shortcuts.

The default shortcuts are Control and right-click for the menu, Control-Space for Quick Open, and Control-Command-V for the clipboard menu. To change them, use Settings > Shortcuts.

Work with other apps

  • Spotlight finds your bookmarks, apps, and commands.
  • Services: select a link in any app, then choose Services > Add to Library. In Finder, select apps or folders and choose the same item.
  • Share: right-click a bookmark or app and choose Share…. Drag a row into any app to drop its link or file.
  • URL scheme: library://open?name=Jira&value=ABC-123 opens a bookmark and fills in its template. library://menu shows the menu. library://search opens Quick Open. Terminal commands can't be opened this way, so a web page can't run one.
  • Shortcuts app: actions for opening and searching items, adding bookmarks and apps, Frequently Used, and the clipboard. Run Terminal Command always asks first. These actions appear only in a build that includes App Intents metadata, which Xcode generates. A build from ./build.sh does not show them yet.

Stay up to date

While Library runs, it checks GitHub for a new release every hour. It also checks at launch if the last check was an hour or more ago.

When a newer version exists, one item appears at the top of the menu. Nothing pops up. To turn checks off, use Settings > General. Choose Check for Updates… at any time. It offers the newer version. If you choose to install it, Library opens Terminal, clones the release, and runs its installer. It does not install silently. See what is sent.

Check links

Library can check that each bookmark's page is still there. It's off by default. To turn it on, use Settings > General > Check links periodically.

  • Once a day while Library is open, Library quickly checks each bookmark. It doesn't download the page.
  • If a site doesn't answer that quick check, Library loads the page and reads only its first 64 KB.
  • Each bookmark is checked at most once a day.
  • A bookmark whose page is missing or can't be reached shows a warning in Edit Library.

To check now, choose File > Check Links.

Back up and restore

Export saves your library to one file, and Restore brings it back. Both are in Settings > General. You can also choose File > Export Library….

  • Export… saves your bookmarks, folders, shortcuts, icons, keywords, colors, templates, and Open at login settings to a JSON file named Library Backup with the date.
  • Restore… opens a backup. Library shows how many items your library has and how many the backup has, then asks you to confirm. Choose Replace Library to continue. Cancel is the default button.
  • Undo brings back the library you had before the restore.

Clipboard items are not in a backup. Pinned clipboard items are encrypted with a key that stays on this Mac. Recently Deleted items in a backup stay deleted after a restore.

Settings

Press ⌘, to open Settings. It has three tabs: General, Shortcuts, and Clipboard.

General

  • Open at login starts Library when you log in.
  • Name new bookmarks from their pages. Library reads each new bookmark's title from its page. Until the title arrives, or when the page has none, the bookmark is named after its host. Off by default.
  • Keep Library in iCloud Drive. See iCloud Drive. Off by default.
  • Check for updates automatically. On by default. See Stay up to date.
  • Check links periodically. Off by default. See Check links.
  • Export… and Restore… save and restore your library. See Back up and restore.
  • Show… opens the welcome screen, which explains Library, lists your shortcuts, and asks for access.
  • Remove tracking parameters when copying links. On by default. Library removes tracking codes such as utm_source, fbclid, and gclid from a link you copy. The rest of the link stays the same, and the saved link is not changed.

Shortcuts

  • Show Library Menu, Show Quick Open, Show Clipboard Menu, and Open Copied Link. Click a field and press the new keys. These work in every app. Open Copied Link opens the web link you last copied. A beep means the clipboard has no link.
  • Library menu opens: At the Pointer or From the Menu Bar.
  • Allow… asks for Accessibility access. Clicks, scrolls, pinches, swipes, and suggesting a selected link need it.
  • Restore Defaults puts the shortcuts back to their defaults: Control and right-click for the Library menu, Control-Space for Quick Open, and Control-Command-V for the clipboard menu. macOS may use Control-Space to switch input sources.

Clipboard

  • Keep clipboard history. On by default. Turn it off to stop recording new copies.
  • Paste into text fields. On by default. If a text field has the keyboard, choosing an item pastes it. Otherwise it copies. This needs Accessibility access.
  • Play copied GIFs. Off by default. See What is sent.
  • Clear History removes the unpinned history.
  • Keep clipboard history across restarts. Off by default. See Keep what you copy.
  • Put the Latest Item on the Clipboard When Library Opens. Off by default. The newest saved item is copied when Library opens, so you can paste it right away. A password copied before a restart could be pasted by someone else at this Mac.
  • Require Touch ID or password to show pinned items. Off by default. See Touch ID or password lock.

Permissions

  • Keyboard shortcuts, hot corners, Quick Open, and the menus don't need any permission.
  • Click, scroll, pinch, and swipe shortcuts, pasting into text fields, and suggesting a selected link need Accessibility access. Turn it on in System Settings > Privacy & Security > Accessibility. Library reads your selection only when you open one of its menus, and it doesn't keep it.

Help menu

The Help menu is in the menu bar at the top of the screen.

  • Library Help opens the Library README on GitHub.
  • Keyboard Shortcuts opens the shortcuts section of the README on GitHub.
  • Welcome Tour… opens the welcome screen. It is the same as Settings > General > Show….
  • Report an Issue… opens a new issue on GitHub.

The GitHub links open in your default browser. Library does not load them.

Troubleshooting

  • A shortcut doesn't work. Another app may use the same keys. Check Settings > Shortcuts. Control-Space can conflict with the macOS input source shortcut.
  • Clicks stop working after a macOS update. Remove Library from Accessibility, then add it again.
  • Open at Login does nothing. Move Library.app to /Applications first. The login item remembers where the app is.
  • Services don't appear. Log out and back in, or run /System/Library/CoreServices/pbs -update.
