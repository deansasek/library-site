Accessibility in Library: VoiceOver, keyboard, and motion

Version 1.6.5 · Updated October 15, 2026

Library supports VoiceOver, keyboard use, Reduce Motion, and Increase Contrast. This page lists what the app does.

Applies to the current release of Library. Last reviewed October 15, 2026.

Keyboard

Library works from the keyboard.

  • ⌃Space opens Quick Open. Type to search, press ↑ or ↓ to move, and press Return to open the result. See Find it with Quick Open.
  • Tab opens a result the other way, or shows its other options.
  • Space previews the selected item in Quick Look.
  • Escape closes Quick Open.
  • In dialogs and sheets, Return confirms the default button, and Escape cancels.

You can change the global keys in Shortcuts.

VoiceOver

Main controls have VoiceOver labels. Examples include Search Library in Quick Open, Actions, Sort, Add, Share, Delete, and Get Info in Edit Library.

Warnings about shortcuts that another app uses are labeled too.

To organize your library, see Organize your library.

Report a problem

If something in Library is hard to use with VoiceOver, the keyboard, or these settings, open an issue on the GitHub issues page.

Motion and contrast

  • Reduce Motion. When Reduce Motion is on, Quick Open's appearance animation is turned off. The Welcome screen does not animate between pages either.
  • Increase Contrast. Quick Open uses system colors, which adapt to light and dark appearance and to Increase Contrast.

Turn these on in System Settings. Library follows them.
